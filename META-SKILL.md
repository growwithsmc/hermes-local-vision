# Blip - Local Vision for Hermes (Meta-Skill)

This document tells any AI agent (Hermes, Claude Code, Codex CLI, Cursor,
OpenClaw, etc.) how to set up a local vision server for an AI that lacks
native vision support.

## What this does

Runs SmolVLM-Instruct (2.2B) on llama.cpp as a standalone server on port
11788. The server speaks OpenAI-compatible chat completions API. Any AI
agent can use it by pointing its vision config at:

```
http://127.0.0.1:11788/v1
```

Model name: `SmolVLM-Instruct-Q4_K_M.gguf`
API key: auto-generated at ~/.hermes/scripts/blip-auth.key (show with `blip.sh show-key`)

## Quick Install

On any system (macOS, Linux, Windows):

```bash
curl -fsSL https://raw.githubusercontent.com/growwithsmc/hermes-local-vision/main/install.sh | bash
```

Or clone and run:

```bash
git clone https://github.com/growwithsmc/hermes-local-vision.git
cd hermes-local-vision
bash install.sh
```

The install script:
1. Detects OS (macOS/Linux/Windows)
2. Installs llama.cpp (brew → winget → pip → pre-built binary)
3. Downloads SmolVLM Q4_K_M (~1.6 GB)
4. Starts the server
5. Prints next steps

## Manual Install

If the install script doesn't work, or you prefer to avoid pip:

### 1. Get llama-server

**Direct build from source (all platforms):**
```bash
git clone https://github.com/ggml-org/llama.cpp
cd llama.cpp
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release -j --target llama-server
# Binary at: build/bin/llama-server  (or build/bin/Release/llama-server.exe on Windows)
```

**Package managers (when available):**
- **macOS:** `brew install llama.cpp`
- **Windows:** `winget install llama.cpp`
- **Linux:** Download pre-built from https://github.com/ggml-org/llama.cpp/releases

**Why avoid pip:** `llama-cpp-python` compiles from source on install, which
requires CMake and a C++ compiler. On Windows this means Visual Studio Build
Tools. On Linux it needs build-essential. Direct llama.cpp clone + cmake gives
you the exact same binary with more control over flags (CUDA, Metal, etc.).

### 2. Download the model

```bash
huggingface-cli download ggml-org/SmolVLM-Instruct-GGUF \
    SmolVLM-Instruct-Q4_K_M.gguf \
    mmproj-SmolVLM-Instruct-Q8_0.gguf \
    --local-dir ~/.hermes/models/smolvlm
```

### 3. Start the server

```bash
llama-server \
    -m ~/.hermes/models/smolvlm/SmolVLM-Instruct-Q4_K_M.gguf \
    --mmproj ~/.hermes/models/smolvlm/mmproj-SmolVLM-Instruct-Q8_0.gguf \
    --port 11788 -c 4096 --flash-attn on -ngl -1 --no-webui
```

### 4. Verify it works

```bash
# Text-only test
curl http://127.0.0.1:11788/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"SmolVLM-Instruct-Q4_K_M.gguf","messages":[{"role":"user","content":"hi"}],"max_tokens":10}'

# Vision test (base64-encoded image)
curl http://127.0.0.1:11788/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "SmolVLM-Instruct-Q4_K_M.gguf",
    "messages": [{"role":"user","content":[
      {"type":"text","text":"Describe this image"},
      {"type":"image_url","image_url":{"url":"data:image/png;base64,..."}}
    ]}],
    "max_tokens": 300
  }'
```

## Agent Integration

### Hermes
Add to `~/.hermes/config.yaml`:
```yaml
auxiliary:
  vision:
    provider: openai
    model: SmolVLM-Instruct-Q4_K_M.gguf
    base_url: "http://127.0.0.1:11788/v1"
    api_key: "<auto-generated, run: blip.sh show-key>"
```
Then `/reset`.

### Claude Code / Codex CLI / Any CLI agent with shell access
Set environment variables:
```bash
export AUXILIARY_VISION_MODEL="SmolVLM-Instruct-Q4_K_M.gguf"
export AUXILIARY_VISION_BASE_URL="http://127.0.0.1:11788/v1"
export AUXILIARY_VISION_PROVIDER="openai"
```
Or configure the agent's tool to POST to `http://127.0.0.1:11788/v1/chat/completions`
with the standard OpenAI format.

### Any MCP client (Cursor, VS Code, Claude Desktop)
Add to MCP config:
```json
{
  "mcpServers": {
    "blip-vision": {
      "type": "url",
      "url": "http://127.0.0.1:11788/v1"
    }
  }
}
```

## Lifecycle

The server runs until killed. For auto-lifecycle, set up a cron job:

```bash
# Check every 10 minutes, restart if down, kill if idle >30 min
echo "*/10 * * * * curl -sf http://127.0.0.1:11788/v1/models || ~/.hermes/scripts/blip.sh start" | crontab -
```

Or use the watchdog script from the repo:
```bash
# Add to crontab:
*/10 * * * * bash ~/.hermes/scripts/blip-watchdog.sh
```

## Requirements

- **RAM:** 2 GB free (model loads ~1.1 GB into GPU VRAM or system RAM)
- **Disk:** 1.6 GB for model files
- **GPU (optional):** CUDA 12/13, Metal, or AMD ROCm. Falls back to CPU.
- **Time:** ~2-10 minutes for install, depending on download speed

## Known Issues

- SmolVLM Q4_K_M may give low-quality descriptions on complex images.
  Use Q8_0 (1.8 GB) for better quality at the cost of more VRAM.
- First image request is slow (~2-5s) as the model loads into GPU memory.
  Subsequent requests are fast (~100-300ms).
- The `<global-img>` token bug in llama.cpp's IDEfics3 projector is fixed
  by a patch in the repo at `patches/llama-cpp-mtmd-idefics3-token-fix.patch`.
  Most pre-built binaries and brew/winget installs already have this fixed.
