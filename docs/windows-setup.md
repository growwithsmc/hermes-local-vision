# Windows Setup Guide

## Prerequisites

- Windows 10/11
- NVIDIA GPU (RTX 30/40 series recommended)
- CUDA 12 or 13 toolkit installed
- Visual Studio 2022 Build Tools (for compiling llama.cpp)
- Git for Windows
- HuggingFace account (for downloading models)

## Step-by-Step

### 1. Install Build Tools

```powershell
# Download Visual Studio 2022 Build Tools
# https://visualstudio.microsoft.com/downloads/#build-tools-for-visual-studio-2022
# During install, select:
#   - Desktop development with C++
#   - Windows 10/11 SDK
```

### 2. Install CUDA

```powershell
# Download CUDA 12.x or 13.x from NVIDIA
# https://developer.nvidia.com/cuda-downloads
# Verify:
nvidia-smi
```

### 3. Build llama-server

```powershell
git clone https://github.com/ggml-org/llama.cpp C:\llama.cpp
cd C:\llama.cpp

# Open "Developer Command Prompt for VS 2022"
# Or from PowerShell:
& "C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\VC\Auxiliary\Build\vcvars64.bat"

cmake -B build -G Ninja ^
    -DGGML_CUDA=ON ^
    -DCMAKE_CUDA_ARCHITECTURES=89 ^
    -DGGML_CPU_ALL_VARIANTS=ON ^
    -DGGML_BACKEND_DL=ON ^
    -DCMAKE_BUILD_TYPE=Release

cmake --build build --config Release -j 12 --target llama-server
```

### 4. Apply the SmolVLM Patch

```bash
# Copy the patch to your llama.cpp directory
cp hermes-smolvlm-addon/patches/llama-cpp-mtmd-idefics3-token-fix.patch C:\llama.cpp\

# Apply
cd C:\llama.cpp
git apply llama-cpp-mtmd-idefics3-token-fix.patch

# Rebuild
cmake --build build --config Release -j 12 --target llama-server
```

### 5. Download the Model

```bash
bash scripts/download-model.sh
```

Or manually via HuggingFace:

```powershell
huggingface-cli download ggml-org/SmolVLM-Instruct-GGUF `
    SmolVLM-Instruct-Q4_K_M.gguf `
    mmproj-SmolVLM-Instruct-Q8_0.gguf `
    --local-dir $env:USERPROFILE\.hermes\models\smolvlm
```

### 6. Configure the Script

Edit `scripts/blip.sh`:
- Set `LLAMA_SERVER` to your build output path
- Or set the `LLAMA_SERVER_PATH` environment variable

### 7. Start the Server

```bash
bash scripts/blip.sh start
```

### 8. Add Hermes Config

Add to `~/.hermes/config.yaml`:

```yaml
auxiliary:
  vision:
    provider: openai
    model: SmolVLM-Instruct-Q4_K_M.gguf
    base_url: "http://127.0.0.1:11788/v1"
    api_key: "<auto-generated, run: blip.sh show-key>"
```

### 9. Set Up Watchdog

```powershell
hermes cron create --name smolvlm-watchdog `
    --schedule "every 10m" `
    --script blip-watchdog.sh `
    --no-agent
```

## Build Output

On Windows with `BUILD_SHARED_LIBS=ON` (default), the build produces:

| File | Size | Purpose |
|------|------|---------|
| `build/bin/llama-server.exe` | 11 KB | Stub launcher |
| `build/bin/llama-server-impl.dll` | 9.4 MB | Server implementation |
| `build/bin/ggml-cuda.dll` | 52 MB | CUDA backend |
| `build/bin/mtmd.dll` | 1.3 MB | Multimodal support |
| `build/bin/llama.dll` | 3.2 MB | Core llama library |

All DLLs must be in the same directory as `llama-server.exe`.
